# Fanta 工具箱 🚀
一个模块化、高可扩展性的 Linux VPS 运维与玩家工具箱，支持跨目录顺畅执行、便捷的模块化管理和完整的 Git 版本控制。
## 📥 一键安装
在你的 Linux 服务器上运行以下命令即可快速安装并配置全局快捷方式： ```bash
git clone [https://github.com/Fantastic1942/fanta.git](https://github.com/Fantastic1942/fanta.git) ~/fanta && chmod +x ~/fanta/fanta1.sh && ln -sf ~/fanta/fanta1.sh /usr/local/bin/fanta && echo -e "\033[32m[成功] Fanta 工具箱安装完成！随时输入 fanta 即可运行。\033[0m"
